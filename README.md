# Chingon Industries

Standalone export of the Chingon Industries marketing website.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

The deployable files are generated in `dist/`.

## GitHub deployment settings

- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

This folder is self-contained and does not require the surrounding Replit workspace.
